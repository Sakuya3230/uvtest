# 段階 21: 輪切りの微調整と縦の継ぎ目

[目次](README.md) ・ 前: [段階 20](20_ring_smooth.md)

## 目的

1. **位置と角度の微調整**: 離したあと、確定する前に、プレビューの輪を腕に沿ってずらす・奥行きに傾ける (描き直さずに詰める)
2. **縦の継ぎ目 (裏側だけ)**: 筒の UV を開くには、輪切りのほかに筒に沿った縦のカットが 1 本要る。腕に沿って描くと、
   カメラから見て奥側の半分だけを継ぎ目にする

| 操作 (輪切りのモード) | 動き |
|---|---|
| 離したあと、ホイール | 輪を切る面に垂直な向き (腕に沿う向き) にずらす。1 目盛り = メッシュの平均のエッジの長さ |
| 離したあと、Shift+ホイール | 輪を傾ける (線を軸に、手前 / 奥へ 3 度ずつ) |
| Shift+ドラッグ | 縦の継ぎ目: 奥側の半分だけをプレビューし、クリックで確定 (ためる)。ホイールでずらすこともできる |

ホイールを受け取るのは、輪切りのモードでプレビューがあり、マウスがビューの上にあるときだけ。それ以外は Maya のカメラのズーム。

## 仕組み

```
ずらす   面 (点, 法線) -> 点を 法線 x 平均のエッジの長さ だけ動かす
傾ける   軸 = 法線 x 視線 (面の中で、視線に垂直な向き = 画面の線の向き)
         法線をその軸のまわりに 3 度回す (ロドリゲスの回転)。回す中心は今の輪の頂点の中心
         -> 画面の上の線の向きはそのままで、輪が手前 / 奥へ傾く (今の視点からは描けない傾き)
どちらも、同じメッシュ・同じ線で境目を求め直す (core.section.section_edges。数 ms)

縦の継ぎ目  腕に沿って描くと、面は腕を縦に切る -> 境目は手前と奥の 2 本 (閉じたメッシュなら端でつながる)
            境目の頂点の中心より視線の先にあるエッジだけ残す (back_half)
```

## 落とし穴

- 押したときに前のプレビューを捨てると、クリックで確定する前に消えてしまう。捨てるのは「ドラッグを始めたとき」
- 粗いメッシュ (段の間隔が半径と同じくらい) では、少し傾けても境目は変わらない (フェースの中心の側が変わらないため)。
  なめらかにする設定では、近くの元のループに吸い付き直す。細かいメッシュほど 3 度ずつの傾きが効く
- 縦の継ぎ目はなめらかにしない (今あるループに吸い付けると縦のループになり、一周の判定と合わないため)

## GUI での確認表

| # | 操作 | 期待 |
|---|---|---|
| 1 | 輪切りで離したあと、ホイール | 輪が腕に沿って 1 段ずつ動く。カメラはズームしない |
| 2 | Shift+ホイール | 輪が手前 / 奥へ傾く (細かいメッシュで分かりやすい) |
| 3 | プレビューが無いときのホイール | 普通にカメラがズームする |
| 4 | Shift+ドラッグで腕に沿って描く | 奥側の半分だけの縦の線。「縦の継ぎ目 N 本」 |
| 5 | クリックで確定 -> C | 輪切りと縦の継ぎ目でカットすると、腕の UV が開ける形になる |
| 6 | Ctrl+Z | 確定が 1 回ずつ戻る |
