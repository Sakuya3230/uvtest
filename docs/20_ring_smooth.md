# 段階 20: 輪切りをなめらかにする

[目次](README.md) ・ 前: [段階 19](19_ring_cut.md) ・ 次: [段階 21](21_ring_adjust_and_seam.md)

## 目的

輪切りの境目は、切る面に一番近いエッジを通るので、斜めの面では段差 (階段) になる。ドラッグ中の速さは保ったまま、
**離したときに 1 回だけ** 整える。設定「なめらか」(既定オン。`-rsm`、欄「輪切り」) でオフにすると、境目のまま。

```
ドラッグ中: 境目 (速い・段差あり) をプレビュー
離す     : 1. 今あるループに吸い付ける -> だめなら 2. 面に沿う道に引き直す -> プレビューを置き換える
クリック : 整えた輪で確定
```

## 仕組み

### 1. 今あるループに吸い付ける

四角形のきれいな腕を軸にほぼ直角に描くと、境目はほとんど一周の段に沿うが、少し斜めだと段差が入る。
境目の真ん中あたりのエッジから、Maya のループ (ダブルクリックと同じ) を求め、それが一周していて切る面に十分近ければ、
境目の代わりに使う。モデラーが作った段差の無いループになる。Maya に聞くのは数回だけ。

### 2. 面に沿う道に引き直す

```
境目の頂点 -> まわり 2 段まで広げた範囲 (band)
手前 / 奥 = 画面で線のいちばん端に写る境目の頂点 A・B
道 1 = A -> B の最小コスト (長さ + 4 x 面からの距離)
道 2 = 道 1 の途中の頂点を外して、もう一度 A -> B
輪 = 道 1 + 道 2 (筒の手前側と奥側。合わせて閉じた輪)
```

- コストに長さが入るので、細かい行ったり来たりは避けられ、面からの距離が入るので面から離れない
- 範囲が狭いので Python の Dijkstra で足りる (4 万頂点の円柱で 3〜9 ms)
- 四角形のメッシュを大きく斜めに切ると、斜めのエッジが無いので段差は残る (三角形があれば斜めのエッジを通る)

## 速さ (40,200 頂点の円柱)

| | 結果 | 時間 |
|---|---|---|
| 四角形・ほぼ直角 | 今あるループ (200 本) | 3 ms |
| 四角形・大きく斜め | 引き直した道 (段差は残る) | 7 ms |
| 三角形・ほぼ直角 | 引き直した道 | 9 ms |
| 三角形・大きく斜め | 引き直した道 (272 -> 223 本) | 8 ms |
