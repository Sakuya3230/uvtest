# UV パスカット 使い方

頂点 / エッジのあいだの最短パスや、選んだエッジで、UV をカット / 縫合するツール。
(作り方の解説は [README.md](README.md) の段階のページ)

## 起動

```python
import UVPathCut
UVPathCut.tool()
```

メッシュを選んでから起動する (オブジェクトでもコンポーネントでもよい。複数可)。対象のメッシュはエッジの選択モードになる。
ツールを使っている間に選んだメッシュも対象に加わる。

## 3 つのモード (Tab で パス -> 選択 -> 輪切り)

| | パス | 選択 | 輪切り |
|---|---|---|---|
| クリック | 1 回目でスタート、次で確定 (エンドが次のスタート) | マウスの下のエッジを選ぶ | プレビューのループを確定 |
| ダブルクリック | - | ループを選ぶ | - |
| ドラッグ | (Shift / Ctrl や、メッシュの外は普通の選択) | 矩形 (一部でもかかる、表の面のエッジ) | 線を描き、一周のループをプレビュー |
| マウスを乗せる | パスのプレビュー (黄) | エッジ (ループの表示がオンならループ) | - |
| カット / 縫合 (C / S) | ためた (まだ実行していない) 区間 | 選んでいるエッジ | ためた区間 |

選択のモードの修飾キーは Maya と同じ: Shift = 切り替え、Ctrl = 外す、Ctrl+Shift = 足す。

### パスのモード

1. 頂点 (V) かエッジ (E) を拾うように選ぶ
2. クリックでスタート (緑)。マウスを動かすと最短パスのプレビュー (黄)
3. クリックで確定。確定した区間はマゼンタ (未実行)。エンドが次のスタートになり、続けて確定できる
4. 「自動」がオンなら確定と同時にカット / 縫合。オフなら区間をためて、C / S (ボタン) でまとめて実行
5. Esc でスタートを取り消す。Ctrl+Z で 1 区間ずつ戻す

区間の色: マゼンタ = 未実行、赤 = カット済み、緑 = 縫合済み。

### 選択のモード

クリック・ダブルクリック・ドラッグでエッジを選び、C / S (ボタン) でカット / 縫合する。
選んだエッジでできている未実行の区間 (パスで作ったもの) は、実行済みになる。

### 輪切りのモード

1. 腕などの筒を、横切るようにドラッグする (腕の外まではみ出してよい)。線に沿う一周のループが黄色で追従する
2. 離すとプレビューが残る。**ホイールで腕に沿ってずらす、Shift+ホイールで手前 / 奥へ傾ける** (確定する前の微調整)
3. クリックで確定 (パスの区間と同じくためる。自動 ON ならすぐカット / 縫合)
4. Esc でプレビューを捨てる。描き直すときは、もう一度ドラッグ

**縦の継ぎ目**: Shift+ドラッグで腕に沿って描くと、カメラから見て奥側の半分だけを継ぎ目にする (確定・ずらすは同じ)。
輪切りと縦の継ぎ目でカットすると、筒の UV が開ける形になる。

線の真下を通り画面の奥へ伸びる面でメッシュを切り分け、その境目のエッジを使う。三角形やポールがあっても必ず一周する。
ドラッグ中は境目 (斜めだと段差) を速く見せ、離したときに整える (設定「なめらか」。既定オン): 近くに一周の
ループがあればそれに吸い付き、無ければ面に沿う、段差の少ない道に引き直す。

## ボタンとキー

ビューの下の中央のボタン。キーはマウスがビューの上にあるときだけ効く (修飾キー付きは Maya に渡す)。

| キー | ボタン | 操作 |
|---|---|---|
| Tab | パス / 選択 / 輪切り | モードを切り替える |
| E / V | (パス: エッジ / 頂点) | 拾うものをエッジ / 頂点にする |
| X | 対称 X / OFF / Maya 対称 Z | 対称を切り替える |
| L | (選択: ループ ON / OFF) | 選択のモードのループの表示 |
| - | (パス・輪切り: 自動 ON / OFF・自動:カット / 縫合) | 確定と同時に実行するか / そのときの操作 |
| C | カット N | パス: ためた区間 / 選択: 選んだエッジをカット |
| S | 縫合 N | 同じく縫合 |
| Shift+Esc | クリア | 確定した区間・スタート・エッジの選択をすべて外す (UV は戻さない。Ctrl+Z で戻せる) |

このツールを使っている間は、ビューの上で E を押しても回転ツールにならない (Q / W / R で抜けられる)。

## 対称 (X)

反対側も同じように操作する (パス: 確定した区間の反対側も / 選択: 選ぶときに反対側も)。反対側はうすい色で見える。

- 反対側は **位置** で決める (面に映した位置から、許容値の中で最も近い頂点)。形が左右でずれていると見つからない
  (見つからない数はログに出る)
- 面は、**Maya の対称がオン (ワールド / オブジェクト) ならその面**、オフならツール設定の「空間」「軸」「許容値」。
  Maya の対称がオンの間は、ツールの対称がオフでも両側に効く (ボタンが「Maya 対称 Z」になる)
- 確定した区間の反対側は確定したときに決まる (あとで対称を切り替えても変わらない)

## ツール設定のウィンドウ

ツールのアイコンをダブルクリックで開く。ボタン・キーで変えた値も合わせて表示される。値は Maya を閉じても残る。

| 欄 | 設定 | 既定 | フラグ | 内容 |
|---|---|---|---|---|
| モード | モード | パス | `-md` | パス / 選択 / 輪切り |
| モード | ループ | オフ | `-lp` | 選択のモードでループを表示する |
| 輪切り | なめらか | オン | `-rsm` | 離したときに輪切りを整える |
| パス | 拾うもの | エッジ | `-pm` | 頂点 / エッジ |
| パス | まっすぐさ | 1.0 | `-st` | 曲がりの少ないパスを選ぶ重み (0 で長さだけの最短。直角 1 回 = 重み × 平均のエッジの長さ) |
| 対称 | 対称 | オフ | `-sy` | 反対側も操作する |
| 対称 | 空間 / 軸 / 許容値 | オブジェクト / X / 0.1 | `-ms` / `-ma` / `-mt` | 対称の面 (Maya の対称がオンの間は灰色) |
| カット / 縫合 | 自動 | オン | `-ac` | 確定と同時に実行する |
| カット / 縫合 | 自動のときの操作 | カット | `-op` | カット / 縫合 |
| 色 | 7 色 | - | `-setColor "キー r g b"` | 面・拾ったもの・スタート・プレビュー・未実行 / カット / 縫合の区間。「色を既定に戻す」 |

スクリプトから: `cmds.uvPathCutCtx("uvPathCutContext", edit=True, mode="select", symmetry=True)`。
「設定を既定に戻す」(`-resetSettings true`) ですべて既定に戻る。

## 注意

- **ロックされたシェイプ** (lockNode) はカット / 縫合できない。パスの確定・選択はでき、カット / 縫合のときは
  そのメッシュを飛ばして警告する (Transform だけのロック・リファレンスのメッシュはカットできる)
- **インスタンス** は形を共有しているので、ほかのインスタンスも同じに変わる (対象にしたときに知らせる)
- **UV が無い** メッシュは、カット / 縫合しても変わらない (対象にしたときに警告する)
- 選択のモードの矩形は面の向きで表 / 裏を決める。へこんだ形で、手前の部分に隠れた表向きの面のエッジは選ばれる
- 選択のモードでは Maya の選択の機能 (ペイント選択・投げ縄・ソフト選択) は使えない
- ツールを使っている間に、ほかのツールでメッシュを動かしたり、トポロジーを変えたりしてもよい。トポロジーが
  変わると区間は別に記録し、Undo などで元のトポロジーに戻れば、前の区間に戻る
- 大きいメッシュ (4.5 万頂点ほど) では、最初のクリックでグラフを作るのに 0.1 秒ほどかかる。numpy / scipy が
  使えると (maya20XX.bat で起動) 最短パス・対称の対応表が速い

## うまくいかないとき

| 症状 | 確かめること |
|---|---|
| 「メッシュを選んでからツールにしてください」 | メッシュを選んでから起動する |
| 反対側が出ない | 対称がオンか (ボタン)。ログの「反対側が見つからない」。許容値を上げる |
| カット / 縫合されない | ログの警告 (ロック・選んでいない・未実行の区間が無い) |
| ボタンが見切れる | ビューを広げる (狭いと 2 段になる) |
