# 保留中の案: UV エディタでの操作

[目次](README.md)

段階 9 のあと (2026-10-12) に検討して、**保留** にした案。今の計画 (段階 18 まで) を仕上げてから、
どれをやるか決める。どれも、外部の変更の検知 (段階 13) まであると作りやすい。

## 前提: 今のツールが UV エディタで動かない理由

- 今のツールは 3D ビュー用のコンテキスト (`MPxSelectionContext`)。UV エディタは UV エディタ用の
  コンテキストしか受け付けないので、このツールを使っている間は UV エディタのクリック・矩形選択が効かない
- マニピュレータ (ホバーと描画) も 3D ビュー専用

## 案 A: UV エディタ用のツール (MPxTexContext)

- UV エディタ用のコンテキストの基底 `MPxTexContext` は、手元のスタブでは **API 1.0 (`maya.OpenMayaMPx`) にしか無い**
  (API 2.0 の `OpenMayaUI` には無い)。1 つのプラグインは API 1.0 か 2.0 のどちらかなので、**別のプラグイン** が要る
- 新しく作るもの: UV の空間でマウスの下の UV の三角形を探す (格子か scipy の kd 木)、UV と頂点の対応
  (継ぎ目では 1 頂点に複数の UV)、描画 (`drawFeedback`) とホバー (`doPtrMoved`)、矩形選択 (`getMarqueeSelection`)
- 使い回せるもの: `core/` (グラフ・最短パス・セッション・設定)、`scene/edit.py` (確定・カット・Undo)
- 手間: 大 (段階 3〜7 をもう 1 回ぶん)

## 案 B: 選択のコールバックのモード

モードをオンにしている間、選択が変わったら (SelectionChanged) 前の点から足した点までを最短パスでつなぐ。
UV エディタでも 3D ビューでも、Maya の普通の選択ツール (矩形選択も) をそのまま使える。手間: 小。

```
クリック -> スタート / Shift+クリック -> 前の点からの最短パスのエッジを選択に足す (自動カットならカット / 縫合)
```

| 注意点 | 対応 |
|---|---|
| コールバックで選択を変えると、また SelectionChanged が届く | 自分で変えている間は無視する印 |
| 選択のコマンドの途中でシーンを変えると Undo の順番が乱れうる | `executeDeferred` で、選択のコマンドが終わってから行う |
| 「ユーザーの選択」と「パスを足す」で Undo が 2 回に分かれる | 直前の select を取り消してから、選択とパスをまとめた 1 回の Undo をやり直す (ウェイトスライダーの方法) |
| どれが新しく足した点か | モードの間だけ `selectPref -trackSelectionOrder` をオン、`ls(orderedSelection=True)` |
| 矩形で一度にたくさん選んだ | 1 つだけ増えたときだけつなぐ |
| UV を選んだとき | 頂点に直してメッシュの上の最短か、同じシェルの中の UV の上の最短か (決める) |
| ほかのツールでも反応する | モードの切り替えで明示的に入る / 出る。入っている間は HUD などで分かるようにする |
| プレビューが無い | 割り切り (気に入らなければ Ctrl+Z) |

Maya の `polySelect -shortestEdgePath` は長さの最短ではない (本数の少ない道に寄る) ので、自前の最短パス (scipy) を使えるのが違い。

## 案 C: UV のメッシュを 3D に作る

UV の配置を形にしたメッシュ (頂点 = 元の UV、位置は (u, v, 0)、面は元と同じ面を UV の番号で張る) を
3D ビューに作り、その上で今のツール (ホバー・プレビュー・クリック・矩形選択・Undo) をそのまま使う。手間: 中。

- 作り方: `MFnMesh.getUVs` / `getAssignedUVs` から `MFnMesh.create` (数万面でも速い見込み)
- 対応表: UV のメッシュのエッジ = 「面の何番目の辺か」で元のエッジに対応。継ぎ目の 2 本は元の同じエッジ
- ツールは UV のメッシュで拾い・探し、確定・カット / 縫合・選択は対応表で元のメッシュのエッジに直して `scene/edit.py` で行う
- 同期: カット / 縫合・Undo / Redo・ほかのツールでの UV の変更のたびに、UV のメッシュと対応表を作り直す (段階 13 の検知を使う)
- UV のメッシュは一時的 (ツールを抜けたら消す・保存しない・Undo に載せない)。元のマテリアルを付けるとテクスチャも見える。真上から見る平行投影のカメラを用意すると UV エディタのように使える
- 性質: パスは UV の上の最短 (UV の長さ)。シェルの外へは進めない (継ぎ目で切れている)。縫合は片方のシェルの縁をなぞれば両側が縫われる。対称は UV の空間 (U = 0.5) か元のメッシュの対称を移すか (決める)
- 別の方法: メッシュを作らずマニピュレータで UV の配置を線で描き、拾い方を自前で作る (ノードは増えないが、拾い方を作る手間とテクスチャが見えない)

## 比べ方

| 方法 | プレビュー | UV エディタで | 手間 | 向いている使い方 |
|---|---|---|---|---|
| 今のツール (3D ビュー) | あり | 使えない | 済み | 3D の形を見ながら切る |
| 案 B 選択のコールバックのモード | なし | そのまま使える | 小 | UV エディタで点を選んでつなぐ |
| 案 C UV のメッシュ | あり | (3D ビューに UV の配置を出す) | 中 | UV の配置を見ながら、プレビュー付きで切る |
| 案 A MPxTexContext | あり | 使える | 大 | (B・C で足りなければ) |

B と C は両方あってもぶつからない (B は「選んでつなぐ」、C は「見ながら切る」)。
