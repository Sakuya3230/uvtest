# 6. モードを足す (手順 19〜21)

[目次](README.md) ・ 前: [5. 実際のシーンに耐える](05_robust.md) ・ 次: [7. 仕上げと全体のコツ](07_finishing.md)

モード (パス / 選択 / 輪切り) は設定 1 つ (`mode`) と、操作の表の `modes=` で、ボタン・キー (Tab で巡回)・
ウィンドウにそろって出る。クリックの振り分けはコンテキストの `doPress` で、モードごとに受け取る。

## 手順 19: 選択のモード

**ゴール**: クリック・Shift / Ctrl・ダブルクリック (ループ)・矩形でエッジを選び、ボタン / C / S でカット / 縫合。

**方法 (ツールが選ぶ)**

- 選択のモードの左ボタンは**基底に渡さず、ツールが選ぶ**。プレビューで拾ったもの (表の面だけ) をそのまま選ぶので、
  表示と結果が必ず一致する
- 選ぶのは MEL の `select -replace / -toggle / -deselect / -add` (Undo できる。名前も付く)。修飾キーは Maya と同じ
  (Shift = 切り替え、Ctrl = 外す、Ctrl+Shift = 足す)
- **ダブルクリックは Qt のイベント (`MouseButtonDblClick`) をキーのフィルターで受け取る**。Maya は 2 回目の押下を
  コンテキストの `doPress` に届けない。ループは `polySelect -edgeLoopOrBorder <エッジ> -noSelection` (ダブルクリックと
  同じ選び方を、選択を変えずに)
- ダブルクリックを 1 回の Undo にする: ループを選ぶ前に、1 回目のクリックの選択を `cmds.undo()` で取り消す
  (直前の Undo の名前がそのクリックのものと同じときだけ)
- 矩形: `doDrag` の drawMgr に点線の枠。離したら、**一部でも枠にかかり** (線分と矩形の交差。中点だけだと半分ほど
  入れないと選ばれない)、表の面に付いているエッジ。全頂点の投影は numpy で `モデルビュー行列 x 射影行列`
  (最初の数点を `worldToView` と照合し、違えば 1 点ずつに戻す)
- 対称なら選ぶときに反対側も選ぶ。ホバーでループのプレビュー (設定でオン / オフ)

**落とし穴 (遠回りした所)**: はじめはクリックを Maya の選択 (基底) に任せ、`setAllowDoubleClickAction` でダブルクリックを
有効にした。すると、Maya の対称で選択が二重になる・隠れた裏側のエッジを拾ってプレビューと違う所が選ばれる・
合わせるためにカメラベースの選択の設定を書き換える必要が出る・その書き換えでダブルクリックが効かなくなる、と続いた。
拾う・ループ・反対側はツールにそろっているので、最初からツールで選ぶほうがよい。

**実装**: [core/selection.py](../../core/selection.py)・[scene/selection.py](../../scene/selection.py)・[tool/selecting.py](../../tool/selecting.py) / 記録 [16_select_mode.md](../16_select_mode.md)

## 手順 20: 輪切り

**ゴール**: 腕などを横切るようにドラッグすると、その位置で一周する輪をドラッグ中ずっとプレビューし、クリックで確定 (ためる)。

**方法 (切る面の境目)**

```
押す     メッシュごとに用意: 頂点の画面の位置・頂点の位置の配列・エッジの両側のフェース (トポロジーごとに覚える)
ドラッグ 線の両端の視線 2 本 -> 切る面 (s0、s0 + r0、s1 + r1 を通る平面。透視でも平行投影でも同じ)
         全頂点の面からの距離 -> フェースの符号 (頂点の距離の和) -> 両側のフェースにはさまれたエッジ
         -> 画面で線の範囲 (線に投げた位置 0〜1) のものだけ       (numpy の配列の計算 1 回ずつ。4 万頂点で 1〜3 ms)
離す     プレビューを残す。クリックで確定 (パスの区間と同じ処理。パスのスタートは変えない)
```

- 筒をフェースで 2 つに分けた境目なので、**トポロジーによらず閉じた輪** (三角形・ポールでも)
- 面は画面の奥へ伸びるので裏側も同じ面で切れる (表 / 裏を調べなくてよい)。胴体なども面で切れるが、線の範囲の外で外れる
- エッジの両側のフェース: 面の角の組 (頂点 a, 次の頂点 b) を整数の鍵にし、エッジの鍵の並びから `searchsorted`
- **ドラッグ中はマニピュレータが描き直されない**。プレビューも `doDrag` の drawMgr に描く。離したとき・確定で描き直す

**落とし穴 (遠回りした所)**: はじめは「今あるループから選ぶ」(線に沿うエッジを候補に、ループを求め、閉じたものの
点数を比べる) にした。ドラッグのたびに Maya にループを聞くので遅く、一周のループが無い (三角形) と見つからなかった。

**実装**: [core/section.py](../../core/section.py)・[scene/ring.py](../../scene/ring.py)・[tool/ring.py](../../tool/ring.py) / 記録 [19_ring_cut.md](../19_ring_cut.md)

## 手順 21: 輪切りの仕上げ

**ゴール**: 段差を減らす・確定前に位置を詰める・筒を開くための縦の継ぎ目。

**方法**

- **なめらかにする (離したときに 1 回)**: (1) 境目の真ん中近くのエッジからループを求め、閉じていて面に十分近ければ
  それに吸い付く (四角形の腕なら段差の無い元のループ)。(2) だめなら、境目のまわり 2 段の頂点だけで
  「長さ + 重み x 面からの距離」の Dijkstra を、手前と奥の 2 本 (2 本目は 1 本目の途中の頂点を外す)。
  ドラッグ中にやると重いので離したときだけ
- **微調整**: 離したあと、ホイールで面を法線の向きにずらす、Shift+ホイールで「法線 x 視線」を軸に回す (奥行きに傾く)。
  ホイールはキーのフィルターで `QEvent.Wheel` を受け取り、プレビューがあるときだけ Maya に渡さない
- **縦の継ぎ目**: Shift+ドラッグで腕に沿って描くと、境目は手前と奥の 2 本。中点が境目の中心より視線の先のもの (奥側) だけ

**実装**: [core/section.py](../../core/section.py) `smooth_ring` / `shift_plane` / `tilt_plane` / `back_half` / 記録 [20_ring_smooth.md](../20_ring_smooth.md)・[21_ring_adjust_and_seam.md](../21_ring_adjust_and_seam.md)
