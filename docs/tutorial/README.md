# UVPathCut 制作チュートリアル

最短パス・選択・輪切りで UV をカット / 縫合する Maya のツール (UVPathCut) を、ゼロから作るための手引き。
どの順番で作るか、各手順でどの方法 (Maya API・仕組み) を使うか、何で確かめるかをまとめる。

- 使い方: [../USAGE.md](../USAGE.md)
- 実際に作った順の記録 (遠回りも含む): [../README.md](../README.md) の段階 0〜21

このチュートリアルは記録とは違い、**最終的にうまくいった方法へまっすぐ進む順番** に並べ直している。
途中で作り直したもの (今あるループから選ぶ輪切り、Maya の選択に任せた選択のモード など) は、各手順の
「落とし穴」に短く残す。

## 前提

| | |
|---|---|
| Maya | 2022〜2027 (Python 3)。Maya API 2.0 (`maya.api.OpenMaya` / `OpenMayaUI` / `OpenMayaRender`) |
| 知識 | Python のクラス、Maya のコンポーネント (頂点 / エッジ / フェース)、`maya.cmds` の基本 |
| 道具 | pytest (Maya を使わない部分)、mayapy (Maya のスタンドアロン)、Maya の GUI (描画・マウス) |
| 任意 | numpy / scipy (Maya の版ごとに `mayapy -m pip install ... -t scripts/site-packages/<版>`)。無くても動くように作る |

## 全体の形

```
plug-ins/uvPathCut.py           登録だけ (クラスはパッケージから毎回引く)
scripts/UVPathCut/
    core/    Maya に依存しない計算 (設定・グラフ・最短パス・描画の一覧・操作の表・断面・対称)  -> pytest
    scene/   Maya のシーンを読む / 変える (メッシュ・Undo できる編集・選択・対応表)               -> mayapy
    tool/    操作と表示 (コンテキスト・マニピュレータ・描画・キー・ツール設定のウィンドウ)        -> GUI
```

依存の向きは `tool -> scene -> core` の一方向。これを最初に決めて守ると、計算の大半を Maya 無しでテストできる。

## 進め方のコツ (全体)

1. **1 手順ずつ、動くものを確かめてから次へ**。GUI でしか分からないこと (描画・マウス・ダブルクリック) が多いので、
   各手順の最後に「試し方」を決めておく
2. **計算は core に純粋関数で書く**。Maya の型 (MPoint など) を core に入れない (タプルにする)。そうすれば pytest で
   速く・細かく確かめられる
3. **表を 1 つ持ち、そこから作る**。設定 (定義表) と操作 (操作の表) を表にして、フラグ・ボタン・キー・ウィンドウを
   表から作る。項目を足すと全部の入り口にそろって出る
4. **Undo に載るのはコマンドだけ**。シーンとツールの状態 (区間のスタック) を変えるものは、すべて 1 つの
   Undo できるコマンドを通す
5. **重い計算は「いつ・何回」を先に決める**。ドラッグのたび (数 ms 以内) / 押したとき / トポロジーごと / 手すきのとき
