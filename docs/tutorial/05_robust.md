## 手順 15: 外部の変更

**ゴール**: ツールを使っている間に、移動・変形・トポロジーの変更・名前の変更があっても、表示と計算を合わせる。

**方法**

- **通知では印を付けるだけ**、比べるのは使う直前 (`MeshModel.sync()`)。通知 = シェイプの dirty
  (`addNodeDirtyCallback`) とワールドの行列 (`MDagMessage.addWorldMatrixModifiedCallback`。親の移動はシェイプを
  dirty にしない)。dirty は 1 回のカットで何度も来る
- 中身の比べ方: トポロジーの鍵 (`MFnMesh.getVertices` の数と hash) と頂点の位置
  - 何も変わらない (自分の UV のカットもここ。特別扱いが要らない)
  - 位置だけ -> 同じエッジで位置を替えたグラフ
  - トポロジー -> グラフを読み直す
- **トポロジーごとにセッションを覚える** (`SessionBook`)。確定のコマンドは自分のセッションを持つので、Undo で
  トポロジーが戻れば前のセッション (区間と Undo の続き) に戻る
- 呼ぶ所: マウスの移動・描く前 (`preDrawUI`)・クリック・操作の前。通知が無ければ何も読まないので何度呼んでも軽い
- 名前を変えられても追うよう、名前ではなく MDagPath を持つ

**実装**: [core/sync.py](../../core/sync.py)・[scene/mesh.py](../../scene/mesh.py) `sync` / 記録 [13_external_changes.md](../13_external_changes.md)

## 手順 16: 複数のメッシュ

**ゴール**: 選んでいる全メッシュを対象にし、カット / 縫合・クリアは全メッシュで 1 回の Undo。

**方法**

- メッシュごとの状態 `MeshTarget` = MeshModel + トポロジーごとのセッション。見分けは `MObjectHandle`
- グラフは**初めてクリックしたときに作る** (ホバーには要らない)。対象が多くても最初は軽い
- ホバーは全メッシュにレイを当て、いちばん手前の面
- スタートは全体で 1 つ (別のメッシュをクリックしたらそこを新しいスタートに。またぐパスは無い)
- 選択の変更 (`MEventMessage` "SelectionChanged") のあと、`maya.utils.executeDeferred` で手すきのときに対象を足す。
  対象は**増えるだけ** (オブジェクトの選択モードで別のメッシュを選ぶと、前のハイライトが外れるため)
- 変更のリストのコマンドは、変えたセッションをリストで持ち、全部に知らせる

**実装**: [scene/targets.py](../../scene/targets.py) / 記録 [14_multiple_meshes.md](../14_multiple_meshes.md)

## 手順 17: 曲がりの重み

**ゴール**: 格子で階段状にならず、曲がりの少ないパスを選べる (設定「まっすぐさ」)。

**方法**

- 1 歩のコスト = 長さ + 重み x 平均のエッジの長さ x (1 - cos 曲がり角)。平均の長さを掛けるので、メッシュの大きさによらない
- 曲がり角は「どのエッジから来たか」で決まるので、**状態を向き付きのエッジ** (e を a->b に進んだら 2e、逆は 2e+1) にする
- scipy の版: 状態のつながりを numpy で (argsort / bincount / repeat でループなし) 作って疎行列にし、仮の始点から
  dijkstra を 1 回。つながりはグラフごとに 1 回
- Python の版: 状態の A*。テストは総当たりの Dijkstra とコストが一致すること

**実装**: [core/turning.py](../../core/turning.py) / 記録 [15_straightness.md](../15_straightness.md)

## 手順 18: 対称

**ゴール**: 反対側も同じように操作する (パスなら区間の反対側も、選択なら選ぶときに反対側も)。

**方法**

- 反対側は**位置**で決める。頂点を面に映した位置から、許容値の中で最も近い頂点 (`scipy.spatial.cKDTree.query(...,
  distance_upper_bound=)`)。エッジは両端の反対側を結ぶエッジ (整数の鍵を `searchsorted` で一度に)。
  無ければ格子で探す (細かいマス -> 見つからないものだけ許容値のマス)
- 対応表は使い回す: トポロジーが同じ間は作り直さない (変形しても組は同じ)・UUID と面とトポロジーを鍵に覚える・
  ツールに入ったら手すきのときに先に作る
- 区間は確定したときに反対側のエッジも持つ (`allEdges()` が両側を返す。選択・カット・描画はそのまま両側になる)
- 対称の面: **Maya の対称がオンならその面を優先** し、ツール設定の欄を灰色にして使っている面を表示。
  Maya の対称の変更には通知が無いので、マウスの移動で 0.5 秒に 1 回まで見る

**落とし穴**: はじめはツールの設定だけにしたが、Maya の対称がオンだと Maya の選択が選択そのものを両側にして、
ツールの対称 (X) と Maya の対称 (Z) が二重にかかった。API に選択の対称を切る方法は無い。

**実装**: [core/mirror.py](../../core/mirror.py)・[scene/mirror.py](../../scene/mirror.py)・[tool/symmetry.py](../../tool/symmetry.py) / 記録 [17_symmetry.md](../17_symmetry.md)
