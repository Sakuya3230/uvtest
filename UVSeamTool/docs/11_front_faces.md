# 段階 11: 表の面だけを拾う

## 目的

頂点を拾うときに、裏の面 (法線がカメラと反対を向く面) を飛ばす。前は最初に当たった面を使ったので、裏の面に当たって
奥の頂点を拾うことがあった。

## 変えたもの

[utils/picking.py](../utils/picking.py) の `pick_vertex` (と、それを使う `vertex_under_cursor`)。作成・編集のどちらの拾い方も、
これを通るので全部に効く。

```
MFnMesh.allIntersections(..., sortHits=True)    レイが当たる面を、近い順に全部
  -> 面の法線 (ワールド) とレイの向きの内積が負 (向き合っている) なら表の面
  -> 最初の表の面の、当たった点にいちばん近い頂点
複数のメッシュ: メッシュごとの最初の表の面のうち、レイの上の長さがいちばん短いもの
```

- 閉じたメッシュ: 見たとおりの手前の面だけを拾う
- 開いたメッシュを裏から見る: その面は飛ばし、奥にある表の面を拾う (無ければ拾わない)
- メッシュの中にカメラがある: 裏の面しか無いので拾わない

## 見送ったこと

- 索引 (accelParams。`autoUniformGridParams`): 索引は MFnMesh の中に持つので、使い回すには MFnMesh を持ち続ける必要がある。
  旧版の落とし穴に「ヒストリーのあるメッシュをカットしたあと、前の MFnMesh を使うと Maya が落ちる」があるので、
  外部の変更の知らせで捨てる作りと一緒に入れる。大きいメッシュでホバーが重いときに足す
- ガイドの線・点を画面で拾うとき (編集) は、まだ隠れているかを見ていない (メッシュの裏に回ったガイドも拾える)

## 試し方

```python
import UVSeamTool.reloader as r; r.reload().reload_modules()
import maya.cmds as cmds, UVSeamTool
cmds.polySphere(); UVSeamTool.tool()
# 球の縁の近くでマウスを動かす -> 手前の頂点だけが橙になる (前は奥の頂点になることがあった)
cmds.polyPlane(); UVSeamTool.tool()   # 平面を下から見る -> 拾わない
```

mayapy (2022 / 2027) でレイを作って、外から見た球は手前を拾う・球の中からは拾わない・平面の裏から見ると平面を飛ばして
奥の球を拾うことを確かめた。
