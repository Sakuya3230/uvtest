# 段階 17c: ガイドの相手 (対称のガイド)

## 目的

対称が効いているとき (17a の `current_plane`) は、作った・編集したガイドの反対側に **実物のガイド (相手)** を作る。
どちらのガイドを編集しても、もう片方を作り直す。カット / 縫合は相手にも当てる。

| 操作 | 対称が効いているとき |
|---|---|
| 作成で点を足す・確定する | 作成中のガイドの相手も点ごとに作り直す (相手は作成中にならない) |
| 編集で点を動かす・挿入・削除 | 編集したガイドの相手を作り直す (相手のほうを編集すれば、元のほうを作り直す) |
| ガイドを消す (Delete・点が 1 つになって消えた・Esc で捨てた) | 相手も消す |
| カット / 縫合 | 対象のガイドと、その相手に当てる |

どれも元の操作と同じ 1 回の Undo。対称がオフの間は相手を合わせない (相手の id は残るので、オンにして編集すれば合う)。

## 仕組み

```
ガイドの組を変える所はすべて tool.guide_edit.apply_many を通る
  -> 対称が効いていれば _with_partners
       core.symmetry.guide_mirror.sync_partners(前の組, 新しい組, 対応表.vertex)
         消えたガイド                -> 相手も消す
         増えた・変わったガイド      -> 点と区間の頂点を対応表で写して、相手を作る / 作り直す (相手の id はそのまま)
                                        今回作り直した相手は、変わったガイドとして扱い直さない (行ったり来たりしない)
         写しても自分と同じ (対称の面の上のガイド) -> 相手を作らない (前の相手があれば消す)
         反対側が見つからない頂点を通る          -> 相手を作らない / 作り直さない (数を警告に出す)
  -> 保存・置き場所・Undo は今までどおり (相手も同じ組の中のガイド)

カット / 縫合: tool.uv_apply.apply_targets が、対称が効いていれば guide_mirror.with_partners で相手を足す
```

- **持ち方**: `Guide.partner` (相手の id。同じメッシュの中)。両方のガイドが互いを指す。JSON にも `"partner"` で保存する
  (無い古いデータは None として読む)
- **区間は求め直さない**: 相手の区間の頂点の列も対応表で写す (最短パスを反対側で求め直すと、同じ長さの別の道を選んで
  左右が食い違うことがあるため。固定の区間もそのまま写せる)
- **比べ方**: 前の組と同じ id のガイドが値として同じなら「変わっていない」(Guide は変えられない値なので `==` で比べる)

## 落とし穴

- 相手は対応表 (17a) で写すので、形が左右でずれていて反対側が見つからない頂点を通るガイドには相手ができない
  (前の相手があればそのまま残る。警告を出す)
- 対称の面をまたぐガイド (片側の点が反対側にある) も写すので、相手が自分と重なる所がある (面の上のガイドだけは作らない)
- api の `cut_guides` / `sew_guides` は確定したガイドすべてに当てるので、相手かどうかは関係ない

## 試し方

```python
import UVSeamTool.reloader as r; r.reload().reload_modules()
import maya.cmds as cmds, UVSeamTool
cmds.polySphere(); UVSeamTool.tool()
# X (対称) -> [作成] で +X 側にガイドを描く -> -X 側に相手ができる (点ごとに追従) -> Enter
# [編集] で相手の点を動かす -> 元のほうも動く / Delete で両方消える / C でカット (両側) / Ctrl+Z で 1 回ずつ戻る
```

mayapy (2027・2022) で、点を足すたびに相手ができる (+X の 199 -> -X の 189)・相手の点を動かすと元が作り直される・
元を消すと相手も消える・Undo で両方戻る・カットで両側 (2 本・4 エッジ)・保存した JSON から partner が戻ることを確かめた。
