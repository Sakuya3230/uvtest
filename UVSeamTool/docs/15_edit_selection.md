# 段階 15: 編集のモードの選択をガイドだけに

## 目的

編集のモードで、何も無い所のクリック・ドラッグを Maya の選択に渡していたので、オブジェクトが選ばれたり、Maya の矩形選択に
なったりして扱いづらかった。**選択はすべてガイドに集中する** (ユーザーの指定)。

| 操作 | 前 | 今 |
|---|---|---|
| 何も無い所をクリック | ガイドの選択を外し、Maya の選択に渡す | ガイドの選択を外すだけ |
| 何も無い所からドラッグ | Maya の矩形選択 | **ガイドの矩形選択** (線が少しでもかかったガイド。白い枠を描く) |
| 修飾キー | - | クリックと同じ (なし = 置き換え / Shift = 切り替え / Ctrl = 外す / Ctrl+Shift = 足す) |
| ドラッグ中の Esc | - | 矩形選択をやめる (選択は変えない) |
| Alt + マウス (カメラ) | Maya | Maya (変わらない) |

編集のモードの左ボタンは、すべてこのサブツールが受け取る。動かした量が 4 ピクセル未満ならクリック。

影響: 編集のモードでクリックしてメッシュを選ぶことはできなくなった (対象に加えるときは、アウトライナーで選ぶか、
作成のモードでメッシュの外をクリック)。

## 決めたこと (ユーザーの選択)

- 編集のモードは Maya の選択を使わない
- 矩形で選ぶのはガイド (点は今までどおりクリックで選ぶ)

## 追加・変更したもの

| ファイル | 中身 |
|---|---|
| [core/guide/guide_picking.py](../core/guide/guide_picking.py) | `guides_in_rect(画面の線, 矩形)` (線分が矩形にかかるか = 端が中・辺と交わる)・`combine_selection_many` (いくつかをまとめて。`combine_selection` はその 1 つだけの形) |
| [tool/edit_picker.py](../tool/edit_picker.py) | `EditPicker`: 画面の上でガイド・矩形・点・挿入する場所を拾う (edit_tool から分けた。300 行のルールのため) |
| [tool/edit_tool.py](../tool/edit_tool.py) | 何も無い所の押下を受け取り、矩形選択 (`_drag_marquee` / `_release_marquee`)。`isBusy` / `cancel` は矩形選択も |
| [tool/painter.py](../tool/painter.py) | `rect2d(矩形, 色)`: 画面の座標で枠を描く (`lineStrip` の draw2D) |

## 仕組み

```
何も無い所で押す -> _marquee_start = (x, y, shift, ctrl)    受け取る (Maya の選択に渡さない)
ドラッグ        -> 4 ピクセル以上動いたら _marquee_rect を作って描く
離す            -> 矩形が無ければ (クリック) 選択を外す (修飾キーなしのとき)
                   矩形があれば EditPicker.guidesInRect -> combine_selection_many
```

## 落とし穴

- 隠れているガイド (メッシュの裏に回ったもの) も、矩形にかかれば選ばれる (クリックと同じ。隠れているかは見ていない)
- 矩形の枠は `lineStrip(点, True)` (2 つ目の引数が draw2D) で、ピクセルの座標のまま描く

## 試し方

```python
import UVSeamTool.reloader as r; r.reload().reload_modules()
import maya.cmds as cmds, UVSeamTool
cmds.polySphere(); UVSeamTool.tool()
# ガイドを 3 本作る -> [編集] -> 何も無い所からドラッグ -> 白い枠、かかったガイドが選ばれる
# Shift / Ctrl を押しながら矩形 -> 切り替え / 外す / 何も無い所をクリック -> 選択が外れ、Maya の選択は変わらない
```

mayapy で、矩形にかかる判定・修飾キーの 4 通り・押す / 短いドラッグはクリック / 矩形選択 / Ctrl で外す / Esc でやめる、
の流れを確かめた (画面に写す所は差し替えた)。

## 追加: ガイドを選んでいるときの矩形は点を選ぶ

メッシュを選んでから、コンポーネントモードで頂点を矩形で選ぶのと同じ考え方 (ユーザーの指定)。

| 状態 | 何も無い所からドラッグ (矩形) | 何も無い所をクリック |
|---|---|---|
| ガイドを選んでいない | ガイドを選ぶ | 何もしない |
| ガイドを選んでいる | **選んでいるガイドの点を選ぶ** (修飾キーは同じ) | 点の選択を外す (点を選んでいなければ、ガイドの選択を外す。Esc と同じ順) |

別のガイドを矩形で選び直すときは、何も無い所をクリックして選択を外してからドラッグする。ガイドの線のクリックで、
ほかのガイドを選ぶことは今までどおりできる (そのとき点の選択は外す)。

| ファイル | 中身 |
|---|---|
| [core/guide/guide_picking.py](../core/guide/guide_picking.py) | `points_in_rect(画面の点, 矩形)` |
| [tool/edit_picker.py](../tool/edit_picker.py) | `pointsInRect(矩形, 選んでいるガイド)`。点を画面に写すのを `_screen_points` にまとめた |
| [tool/edit_tool.py](../tool/edit_tool.py) | `_release_marquee` がガイドを選んでいれば点を選ぶ。何も無い所のクリックは `abort` (点 -> ガイドの順に外す) |

落とし穴: 何も無い所を押したときに点の選択を外すと、Shift を押した矩形で点を足せない。点の選択を外すのは、ガイドの線を
クリックしたときだけにした。

mayapy で、ガイドなし -> 矩形でガイド・ガイドあり -> 矩形で点・Shift の矩形で点を足す / 切り替え・クリックで点 -> ガイドの
順に外れることを確かめた (画面に写す所は差し替えた)。

## 追加: 作成のモードも Maya の選択を使わない

ユーザーの指定で、作成のモードも左ボタンをすべて受け取る (メッシュの外・Shift / Ctrl 付きのクリックは何もしない)。
Maya の選択を使うのは選択のモードだけになった。メッシュを対象に加えるのは、アウトライナーで選ぶか、選択のモードの
Maya の選択で選んだとき。
