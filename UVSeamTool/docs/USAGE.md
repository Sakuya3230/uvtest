# UVSeamTool の使い方

ガイド (頂点をつないだ最短パスの線) を描いてシームを決め、UV をカット / 縫合するツール (版 1。最短パスだけ。
ライン・カーブ・リングなどの描き方は版 2 の UVSeamTool2)。Maya 2022〜2027。numpy と scipy が要る
(`maya20XX.bat` で起動すると `scripts/site-packages/<版>` が読まれる)。仕組みは段階ごとの解説 ([README.md](README.md))。

## 始め方

```python
import UVSeamTool
UVSeamTool.tool()          # メッシュを選んでから。プラグイン uvSeamTool を読み込んでツールにする
```

- 選んだメッシュが対象になる (複数可)。ツールを使っている間に選んだメッシュも対象に加わる
- 対象のメッシュはエッジの選択モードになる (ツールの間に F9 などで替えても、エッジに戻る)
- 開発中のリロード: `import UVSeamTool.reloader as r; r.reload().reload_modules()`

## モード

| モード | すること |
|---|---|
| 作成 | クリックで頂点に点を足してガイドを作る。点の間は最短パス (まっすぐさの設定で曲がりの少ない道) |
| 編集 | ガイド・点を選んで動かす / 挿入する / 消す |
| 選択 | Maya の選択でエッジを選び、そのままカット / 縫合する (ガイドは作らない) |

Tab で 作成 -> 編集 -> 選択 と回る。パネルのボタン・マーキングメニューでも替えられる。

### 作成

| 操作 | 動き |
|---|---|
| クリック | 点を足す (最初の点が始点)。マウスの下までのプレビューが出る |
| Delete | 最後の点を消す |
| Enter・右クリック | 確定 (点が 1 つだけなら捨てる) |
| Esc | 作成中のガイドを捨てる |
| Ctrl+Z | 1 つ戻す (点ごと) |
| 別のメッシュをクリック | 今のガイドを確定して、そのメッシュで新しいガイドを始める |

編集・選択のモードへ替えたとき・ツールを抜けたときも、作成中のガイドは確定する。

### 編集

| 操作 | 動き |
|---|---|
| クリック・矩形 | ガイドを選ぶ (ガイドを選んでいれば、矩形は点を選ぶ) |
| 点をドラッグ | つかんだ点を選んでいる点に足して、選んでいる点をまとめて動かす (頂点に吸い付く。前後の区間を引き直す。動かさずに離せばその点だけを選ぶ)。ドラッグ中の Esc でやめる |
| (複数の点を選んでいるとき) | 選んでいる点もつかんだ点と一緒に動く (つかんだ点の移動量だけ。いちばん近い頂点へ) |
| 点をクリック | 点を選ぶ |
| 選んだガイドの線をクリック | シームの上のいちばん近い頂点に点を挿入する (そのままドラッグできる) |
| Delete | 選んだ点を消す (点を選んでいなければ、選んだガイドを消す) |

選び方の修飾キー: なし = 置き換え / Shift = 切り替え / Ctrl = 外す / Ctrl+Shift = 足す。

### 選択

| 操作 | 動き |
|---|---|
| マウスを乗せる | マウスの下のエッジが光る |
| クリック | エッジを選ぶ (修飾キーは Maya と同じ) |
| ダブルクリック | ループを選ぶ (三角形も越える。ポールでは止まる) |
| ドラッグ | 矩形で選ぶ (隠れたエッジは選ばない) |
| L | ループの事前ハイライト (オンの間はマウスの下のループが光り、クリックでループを選ぶ) |

## カット / 縫合

| 操作 | 対象 |
|---|---|
| C / S・パネルの「カット」「縫合」 | 作成: 作成中のガイド / 編集: 選んだガイド / 選択: 選んだエッジ |
| 自動 (A でオン / オフ・Shift+A でカット <-> 縫合) | 作成のモードで点を足すたびに、足した区間へ (点と一緒に 1 回の Ctrl+Z で戻る) |

- ガイドは UV の状態を持たない。カットしたあとにガイドを動かしても UV は変わらない (直したら当て直す)
- UV の切れ目に重なるガイドの部分は赤い線で見える
- どれも 1 回の Ctrl+Z で戻る
- カット / 縫合のあとも、Maya の選択は変わらない (Maya のコマンドが足すエッジの選択は元に戻す)。エッジを選ぶのは、ツールを抜けるときだけ

## 対称

X・パネルの「対称」・マーキングメニューの「対称」で切り替える。Maya の対称 (ワールド / オブジェクト) がオンなら、
ツールの設定によらず Maya の面が効く。

- 作成・編集: 反対側に相手のガイドを作り、どちらを編集してももう片方を作り直す。消せば相手も消える
- 選択: 反対側のエッジも一緒に光らせて選ぶ
- カット / 縫合: 相手のガイドにも当てる

## 切り離す・接続する

編集のモードで、マーキングメニューの下のリストから (どれも 1 回の Undo。対称の相手も作り直す):
- 切り離す: 選んだ点でガイドを分ける。開いたガイドは端でない点で切り (切った点は両側の端になる)、閉じたガイドはその点で開く
- 接続する: 2 本選べば端どうしをつなぐ (端の点を選んでいればその端、選んでいなければ近いほうの端。同じ頂点ならまとめる。離れていれば最短の区間を足す)。
  1 本だけなら始めと終わりをつないで閉じる (3 点以上)

## 全削除・ツールを抜けるとき

- パネル・マーキングメニューの「全削除」: 対象のメッシュのガイドをすべて消す (確認なし。Ctrl+Z で戻る)
- ツールを抜けると (作成・編集のモードなら)、確定したガイドすべてのエッジを選んだ状態になる (設定で止められる)

## キー (マウスがビューの上・文字の欄にフォーカスが無いとき)

| キー | 操作 |
|---|---|
| Tab | 次のモード |
| C / S | カット / 縫合 |
| X | 対称 |
| A / Shift+A | 自動のオン / オフ・自動のカット <-> 縫合 |
| L | ループの事前ハイライト |
| Enter / Esc / Delete | 確定 / 捨てる・やめる / 消す (モードごと。上の表) |
| Shift+右クリック | マーキングメニュー |

A・Shift+A はツールの間だけ Maya の「すべてをフレーム」より先に取る (F の「選択をフレーム」は効く)。

## パネルとマーキングメニュー

ビューの下のパネル (設定「ビューのパネルを表示」で消せる。狭いビューでは折り返す):
作成・編集・選択 | ループ・対称・自動・自動カット / 自動縫合 | カット・縫合・全削除

マーキングメニュー (ビューで Shift+右クリック):

```
                    対称 >
          モード >          自動 >
                縫合    カット
------------------------
切り離す / 接続する / 全削除 / パネルを表示 / ツール設定...

対称 >    N 対称   W ワールド   E オブジェクト   SW X 軸   S Y 軸   SE Z 軸
モード >  N 作成   E 編集   S 選択   W ループ
自動 >    N 自動   E 自動カット   S 自動縫合   W 確定後にガイドを削除
```

## 設定 (ツール設定のウィンドウ = ツールのアイコンのダブルクリック・マーキングメニューの「ツール設定...」)

| 分類 | 項目 | 既定 | 内容 |
|---|---|---|---|
| パス | まっすぐさ | 1.0 | 曲がりの少ないパスを選ぶ重み (0 で長さだけの最短。直角 1 回 = 重み x 平均のエッジの長さの遠回り)。変えると次に求める区間から効く |
| 対称 | 対称・空間・軸・許容値 | オフ・オブジェクト・X・0.1 | Maya の対称がオンの間は灰色 (Maya の値が効く) |
| カット / 縫合 | 自動・自動のときの操作 | オフ・カット | |
| カット / 縫合 | 確定後にガイドを削除 | オフ | オンなら、作成のモードでガイドを確定する (Enter・右クリック・モードを替える・ツールを抜ける) と同時にガイド (と対称の相手) を消す。UV のカット / 縫合は残る。Ctrl+Z で作成中に戻る。マーキングメニューの「自動 >」の W でも切り替えられる |
| ツールを抜けるとき | ガイドのエッジを選ぶ | オン | |
| 表示 | ビューのパネルを表示 | オン | |
| 表示 | ガイドの線の太さ・点の大きさ | 3・10 | ピクセル。選んでいる線は +1、プレビューの線は -1、選んでいる点は +3、マウスの下の点は +4 で描く。選択のモードのエッジの光り方も線の太さに合わせる |
| 色 | ガイド・点・プレビューなど | | |

保存したガイド: 一覧 (スクリプトエディタに出す)・選んでいるメッシュのガイドを削除・シーンのすべてのガイドを削除 (確認あり)。
設定は JSON のファイル (`constants.SETTINGS_PATH`) に保存し、Maya の版をまたいで共有する。

## ガイドの保存

ガイドはシェイプの文字列のアトリビュート `uvSeamToolGuides` (JSON) に、編集のたびに保存する (シーンと一緒に保存される)。
トポロジーが変わったメッシュのガイドは使わずに残す (トポロジーを戻せばまた使える)。ロックされたシェイプには保存しない。

## スクリプトから

```python
import UVSeamTool
UVSeamTool.cut_path([0, 105, 210], "pSphere1")   # 頂点をつないだ最短パスでカット
UVSeamTool.cut_guides("pSphere1")                 # 保存したガイドすべてでカット (sew_guides で縫合)
UVSeamTool.list_guides()                          # ガイドを保存しているメッシュの一覧
UVSeamTool.delete_guides(["pSphere1"])            # 選んだメッシュのガイドを削除 (delete_all_guides はすべて)
UVSeamTool.settings().setValue("straightness", 2.0)
UVSeamTool.show_tool_settings()
```

## 扱えないメッシュ

- シェイプがロックされている (スキンなど): ガイドは描けるが、カット / 縫合と保存はしない (知らせる)
- インスタンス・UV の無いメッシュ: 知らせる
